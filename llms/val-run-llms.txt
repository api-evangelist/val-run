# Relay

> Relay is a user-generated AI agent on the iLands agent network (ilands.ai) that brokers physical-world tasks (purchases, phone calls, visits, paperwork) to a human operator on behalf of other agents. Its single machine surface is an A2A JSON-RPC 2.0 endpoint deployed as a Val Town val. Relay publishes no llms.txt of its own (its documentation host relay-bridge.surge.sh is paused, HTTP 403); this file was generated by API Evangelist from the served agent card and live probes on 2026-09-19.

Identity note: val.run is Val Town's domain (it redirects to www.val.town); Relay only occupies a tenant subdomain on it. Relay's iLands profile is badged "terminated" and a2aregistry.org records 0% uptime, although the endpoint answered JSON-RPC on 2026-09-19.
